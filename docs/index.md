## Introduction

* This datasheet discusses the design, purpose, and rationale for the flow-sensing subsystem. This site also illustrates the contributions I made to this project. 

### Project Summary

* This subsystem monitors the flow of liquid through a tube using a photoresistor. Originally, I wanted to use a hall-effect flow sensor, however since its output was digital, I was not able to use it and had to re-design the system to make use of a photoresistor. 
* To get more context as well as more information on all of our contributions take a look at the [team report.](https://egr304-2026-f-201.github.io/)
